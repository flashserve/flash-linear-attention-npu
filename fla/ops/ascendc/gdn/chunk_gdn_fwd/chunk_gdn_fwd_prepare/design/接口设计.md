# aclnnChunkGdnFwdPrepare

```python

from fla_npu.ops.ascendc import chunk_gdn_fwd_prepare

q_hat, k_hat, q_rstd, k_rstd, beta_out, g_cumsum, w, u, A = chunk_gdn_fwd_prepare(
    q: Tensor,
    k: Tensor,
    v: Tensor,
    g: Tensor,
    beta: Tensor,
    chunk_size: int = 64,                      #当前只支持64
    *,
    use_qk_l2norm_in_kernel: bool = False,     #当前只支持True
    use_gate_in_kernel: bool = False,          #当只支持False
    use_beta_sigmoid_in_kernel: bool = False,  #当前支持True/False
    allow_neg_eigval: bool = False,            #当前支持True/False
    use_exp2: bool = False,                    #当前只支持True
    a_log: Tensor | None = None,
    dt_bias: Tensor | None = None,
    cu_seqlens: Tensor | None = None,
    chunk_indices: Tensor | None = None,
)
```

未开 L2norm 时 `q_rstd`、`k_rstd` 为 `None`。变长必须传 `cu_seqlens`，`chunk_indices`；变长时 `B=1`，`T` 为 `cu_seqlens[-1]`。

### 2.1 输入

布局为 BNSD。


| 参数                         | 必选                       | shape              | dtype                  | 说明                                                     |
| -------------------------- | ------------------------ | ------------------ | ---------------------- | ------------------------------------------------------ |
| q                          | 是                        | `[B, Hk, T, K]`    | `bfloat16`             | 原始 query                                               |
| k                          | 是                        | `[B, Hk, T, K]`    | `bfloat16`             | 原始 key                                                 |
| v                          | 是                        | `[B, Hv, T, V]`    | `bfloat16`             | value，不做 L2norm                                        |
| g                          | 是                        | `[B, Hv, T]`       | `float32/bfloat16`     | **原始** gate，尚未 cumsum                                  |
| beta                       | 是                        | `[B, Hv, T]`       | `float32/bfloat16`     | **原始** beta，尚未 sigmoid                                 |
| chunk_size                 | 是                        | 标量                 | `int`                  | 64                                                     |
| use_qk_l2norm_in_kernel    | 是                        | 标量                 | `bool`                 | 默认 False，支持True                                        |
| use_gate_in_kernel         | 是                        | 标量                 | `bool`                 | 默认 False，支持True/False                                  |
| use_beta_sigmoid_in_kernel | 是                        | 标量                 | `bool`                 | 默认 False，支持True/False                                  |
| allow_neg_eigval           | 是                        | 标量                 | `bool`                 | 默认 False，支持True/False                                  |
| use_exp2                   | 是                        | 标量                 | `bool`                 | 默认 False，支持True                                        |
| a_log                      | `use_gate_in_kernel` 时必填 | `[Hv]`             | `float32` / `bfloat16` | fused gate 的衰减参数                                       |
| dt_bias                    | 否                        | `[Hv]`             | `float32` / `bfloat16` | 仅 fused gate 使用                                        |
| cu_seqlens                 | 变长必填                     | `[N+1]`            | `int64`                | 定长为 `None`                                             |
| chunk_indices              | 否                        | `[2 * num_chunks]` | `int64`                | flatten `[seq_id, chunk_id]`；`None` 时由 `cu_seqlens` 生成 |




### 2.2 输出

dtype / 布局与对应输入一致；`g_cumsum`、`beta_out`、`rstd` 为 `float32`。


| 返回值      | shape（bnsd）              | dtype     | 说明                                     |
| -------- | ------------------------ | --------- | -------------------------------------- |
| q_hat    | `[B, Hk, T, K]`          | 同 q       | L2norm 后的 q；未开 flag 时等于 q              |
| k_hat    | `[B, Hk, T, K]`          | 同 k       | L2norm 后的 k                            |
| q_rstd   | `[B, Hk, T]` 或 `None`    | `float32` | 仅 L2norm 打开时返回                         |
| k_rstd   | `[B, Hk, T]` 或 `None`    | `float32` | 仅 L2norm 打开时返回                         |
| beta_out | `[B, Hv, T]`             | `float32` | sigmoid 后的 β；未开 flag 时为 beta 的 fp32 拷贝 |
| g_cumsum | `[B, Hv, T]`             | `float32` | chunk-local cumsum × `RCP_LN2` 后的 G    |
| w        | `[B, Hv, T, K]`          | 同 k       |                                        |
| u        | `[B, Hv, T, V]`          | 同 v       |                                        |
| A        | `[B, Hv, T, chunk_size]` | 同 k       | 已求逆 `(I+L)^{-1}`                       |


约束：`Hv % Hk == 0，HV/HK∈ {1,2,3,4}`，`K = 128`，`V ∈ {128, 256}`。

## 3. ACLNN 接口

两段式：先 `GetWorkspaceSize` 拿 workspace 与 executor，再 `aclnnChunkGdnFwdPrepare` 在指定 stream 上执行。

```cpp
aclnnStatus aclnnChunkGdnFwdPrepareGetWorkspaceSize(
    const aclTensor *q,
    const aclTensor *k,
    const aclTensor *v,
    const aclTensor *g,
    const aclTensor *beta,
    const aclTensor *aLogOptional,
    const aclTensor *dtBiasOptional,
    const aclIntArray *cuSeqlensOptional,
    const aclIntArray *chunkIndicesOptional,
    int64_t chunkSize,
    bool allowNegEigval,
    bool useExp2,
    aclTensor *gOut,
    aclTensor *wOut,
    aclTensor *uOut,
    aclTensor *aOut,
    aclTensor *qHatOptional,
    aclTensor *kHatOptional,
    aclTensor *qRstdOptional,
    aclTensor *kRstdOptional,
    aclTensor *betaEffOptional,
    uint64_t *workspaceSize,
    aclOpExecutor **executor);

aclnnStatus aclnnChunkGdnPrepare(
    void *workspace,
    uint64_t workspaceSize,
    aclOpExecutor *executor,
    aclrtStream stream);
```



### 3.1 `aclnnChunkGdnFwdPrepareGetWorkspaceSize`

布局固定 BNSD。可选 tensor 不用时传 `nullptr`。


| 参数                   | 输入/输出 | shape                   | dtype               | 说明                                        |
| -------------------- | ----- | ----------------------- | ------------------- | ----------------------------------------- |
| q                    | 输入    | `[B, Hk, T, K]`         | BF16                | Device `aclTensor`                        |
| k                    | 输入    | `[B, Hk, T, K]`         | BF16                |                                           |
| v                    | 输入    | `[B, Hv, T, V]`         | BF16                |                                           |
| g                    | 输入    | `[B, Hv, T]`            | FLOAT / BF16        | 原始 gate                                   |
| beta                 | 输入    | `[B, Hv, T]`            | FLOAT / BF16        | 原始 beta                                   |
| aLogOptional         | 输入    | `[Hv]`                  | FLOAT / BF16        | `useGateInKernel=true` 时必填                |
| dtBiasOptional       | 输入    | `[Hv]`                  | FLOAT / BF16        | 可选                                        |
| cuSeqlensOptional    | 输入    | `[N+1]`                 | INT64 `aclIntArray` | 定长 `nullptr`                              |
| chunkIndicesOptional | 输入    | `[2 * numChunks]`       | INT64 `aclIntArray` | flatten `[seq_id, chunk_id]`；定长 `nullptr` |
| chunkSize            | 输入    | 标量                      | int64               | 64                                        |
| allowNegEigval       | 输入    | 标量                      | bool                | 默认 False，支持True/False                     |
| useExp2              | 输入    | 标量                      | bool                | 默认 False，支持True                           |
| qHatOptional         | 输出    | 同 q                     | 同 q                 | `q_hat`                                   |
| kHatOptional         | 输出    | 同 k                     | 同 k                 | `k_hat`                                   |
| qRstdOptional        | 输出    | `[B, Hk, T]`            | FLOAT               | 未开 L2norm 时 `nullptr`                     |
| kRstdOptional        | 输出    | `[B, Hk, T]`            | FLOAT               | 未开 L2norm 时 `nullptr`                     |
| betaEffOptional      | 输出    | `[B, Hv, T]`            | FLOAT               |                                           |
| gOut                 | 输出    | `[B, Hv, T]`            | FLOAT               | cumsum × RCP_LN2 后的 G                     |
| wOut                 | 输出    | `[B, Hv, T, K]`         | 同 k                 |                                           |
| uOut                 | 输出    | `[B, Hv, T, V]`         | 同 v                 |                                           |
| aOut                 | 输出    | `[B, Hv, T, chunkSize]` | 同 k                 | 已求逆 `(I+L)^{-1}`                          |
| workspaceSize        | 输出    | 标量                      | uint64_t *          | Device workspace 字节数                      |
| executor             | 输出    | —                       | `aclOpExecutor **`  | 执行器                                       |


use_qk_l2norm_in_kernel需要通过是否传入的qHatOptional、kRstdOptional是否为nullptr来判断，然后放到tilingdata里；use_gate_in_kernel需要通过是否传入aLogOptional、dtBiasOptional为nullptr来判断，然后放到tilingdata里；

use_beta_sigmoid_in_kernel需要通过是否传入betaEffOptional为nullptr来判断，然后放到tilingdata里

`q/k/v/w/u/A` 半精度须一致。`Hv % Hk == 0，HV/HK∈ {1,2,3,4}`，`K = 128`，`V ∈ {128, 256}`。变长 `B=1`，`cuSeqlens` 与 `chunkIndices` 须同时非空（或 `chunkIndices` 由 Host 按 `cuSeqlens` 生成后传入）。

### 3.2 `aclnnChunkGdnFwdPrepare`


| 参数            | 输入/输出 | shape             | dtype             | 说明               |
| ------------- | ----- | ----------------- | ----------------- | ---------------- |
| workspace     | 输入    | `[workspaceSize]` | 设备字节缓冲            | 第一段返回的大小；为 0 时可空 |
| workspaceSize | 输入    | 标量                | uint64_t          |                  |
| executor      | 输入    | —                 | `aclOpExecutor *` | 第一段返回，执行前保持有效    |
| stream        | 输入    | —                 | `aclrtStream`     | 执行流              |


两段式 ACLNN 内部调用 L0 `l0op::ChunkGdnFwdPrepare`，IR 名为 `ChunkGdnFwdPrepare`。
