# VdnAddDiagonal 设计

方案设计规则版本：V2

工程结构遵循 `ENGINEERING-STRUCTURE V1`。每个 128 × 128 方阵有两个 64 × 64 对角块，每个块由一个 AIV 任务处理。host 用 `min(2 * N, 平台 AIV 数)` 设置 blockDim。同一核跨批次复用已经装入 UB 的 `2I` 对角块。

| 模板字段 | 取值 | 动态 tiling 数据 |
| --- | --- | --- |
| `SECTOR_WIDTH` | 64 | 批次矩阵数 |

两个 UB 缓冲区分别保存当前块与共享对角块，共 32 KiB。MTE2 以 128 个元素的源行距读取 64 × 64 子块，经向量加后由 MTE3 按相同行距写回。每个地址最多被一个核写入。矩阵其余两个非对角块保留原值。L0 将输出绑定到输入的存储地址，内核不分配 GM 临时张量。

宿主侧的矩阵数占 8 字节。910B 二进制的 `opParaSize` 另含一个 8 字节运行时字，host 置零并发布共 16 字节。

## Stage 0 · Vector 原位校正

对 `-M @ X` 的两个对角子块分别加上同一个 64×64 的 `2I`，另两个子块无需读写。每个核先读入 16 KiB 的常量子块。每个工作项再读 16 KiB 的校正矩阵，等待 MTE2→V 后相加，再以 V→MTE3 通知写回 16 KiB。下一项复用 UB 之前等待当前写回。UB [0,16 KiB) 保存并覆盖当前子块，[16,32 KiB) 常驻 `2I`。例如 64 帧 × 7 头，896 个工作项分给 48 个 AIV，每核执行 18 或 19 项。
