# 算子概览

Ascend C 使用 `fla_npu.ops.ascendc`，同时提供带 `npu_` 前缀和不带前缀的入口；Triton 使用 `fla_npu.ops.triton`。各算子的参数和支持范围见名称链接，安装见根 [README](../README.md)，旧调用方式迁移见 [兼容与迁移指南](兼容与迁移指南.md)。

<a id="atk-op-options"></a>

## Ascend C 算子

“算子工程名”对应 `fla/ops/ascendc` 下的源码工程目录名，可通过 `build.sh --ops=<工程名>` 或 `FLA_NPU_OPS=<工程名>` 筛选构建；存在同名 ATK 测试工程时，也可通过 `tests/atk/run_test_cpu.sh -op=<工程名>` 指定测试，详见 [ATK 说明](../tests/atk/README.md)。`-` 表示无本仓独立算子工程。
