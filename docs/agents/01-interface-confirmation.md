# 接口确认

本阶段把用户提供的参考资料、参考实现和需求整理成可逐项确认的接口契约。用户确认数学语义、输入输出和支持范围后，进入 CPU 标杆生成。

## 开始前需要的信息

用户至少提供一种能够明确来源和版本的参考资料或参考实现：

- 参考实现代码或固定 commit 的链接。
- 已发布接口文档、schema 或 API 定义。
- 能表达输入、输出和属性语义的测试或可运行示例。
- 论文或公式用于补充说明，工程参考实现、接口文档或测试用于确定实际接口行为。

同时确认参考资料或参考实现的来源、版本、许可证约束、预期支持范围和目标调用入口。信息齐全后开始确认接口；缺少的信息列成清单并请用户补充或确认。

## 接口依据

| 材料 | 用途 |
| --- | --- |
| 公开接口、接口文档和用户明确说明 | 确定对外契约 |
| 测试和示例 | 确定边界、默认值和异常行为 |
| 参考实现 | 分析公式、计算顺序、状态传播和数值细节 |
| 论文或相邻实现 | 解释和交叉验证 |

材料结论不一致时，列出具体差异、可能原因和影响，由用户确认最终接口语义。

## 既有算子修改路由

先比较当前接口契约、CPU 标杆、设计、实现和测试，列出本次变化及保持不变的内容。差异清单之外的接口和行为保持不变。

| 发现的变化 | 起始阶段 | 后续流程 |
| --- | --- | --- |
| 公开参数、返回值、默认值、ABI、数学语义、dtype/layout 行为、支持范围或异常行为变化 | `01` | 确认接口差异后执行 `02` → `03` → `04` → `05` |
| 接口不变，仅 CPU 标杆或预期结果需要修改 | `02` | 更新并验收 CPU 标杆后执行 `03` → `04` → `05` |
| 接口和 CPU 标杆正确，仅当前实现不符合已有约定 | `03` | 完成修复设计、实现和回归测试，即 `03` → `04` → `05` |
| 对外行为不变，仅提升性能 | `03` | 按 `03` 的优化要求完成基线、方案和实验，再执行 `04` → `05` |

## 接口契约

接口确认记录至少包含：

| 项目 | 需要确认的内容 |
| --- | --- |
| 接口名称与层级 | 算子名、公开入口、L2/L0/aclnn/Python 层级和版本 |
| 输入 | 名称、顺序、required/optional、shape、dtype、format、layout、device 和语义 |
| 属性 | 名称、类型、默认值、取值范围、是否可由 descriptor 或已有信息推导 |
| 输出 | 数量、顺序、shape、dtype、layout、状态输出和别名关系 |
| 数学语义 | 公式、计算顺序、归一化、缩放、mask、状态更新和返回值语义 |
| 边界行为 | 空输入、partial chunk、padding、无效区、极端值和支持边界组合 |
| 错误行为 | host 校验、错误类型、返回码和报错条件 |
| 支持范围 | SoC、fixed/varlen、head 关系、K/V/chunk 维度，以及本次需要支持的场景 |
| 性能目标 | 目标 shape、当前性能、目标指标，以及为保证正确性而准备的备用实现及其使用条件 |

对预留参数，明确其公开形态、当前处理方式、host 拦截和未来兼容策略。支持声明以已经完成验证的能力为范围。

## 接口与 ABI 约束

- 优先复用已有接口信息；可由 tensor descriptor、InferShape、host tiling、tiling data 或 workspace 推导的信息保留在内部实现中。
- op_host、InferShape、tiling、kernel、op_api、schema、Python wrapper、公开文档和测试中的名称、顺序、类型及默认值必须一致。
- 同一算子在所有支持 SoC 上保持同一公开接口和 L0 原型，平台差异留在实现内部。

## 阶段输出

提交给用户确认的内容应简洁、可逐项判断：

1. 参考资料或参考实现的来源和固定版本。
2. 接口签名与逐参数说明。
3. 数学语义和状态语义。
4. 支持矩阵、性能目标和本次需要支持的场景。
5. 边界、异常及兼容性规则。
6. 尚未解决的问题和需要用户选择的差异。
7. 对既有算子的接口或功能修改，还需列出改变项、保持不变项，以及接下来从哪个阶段继续。

新增接口或改变既有接口契约时，用户确认接口和语义，且所有影响开发的问题都有明确答案后，进入 [`02-reference-generation.md`](02-reference-generation.md)。如果接口契约和 CPU 标杆均正确，只需修复当前实现，则按上表直接进入 `03`。
