## Stable-only 合并适配验证（2026-10-23）

基于主干 `8762b613` 的 Stable-only 提交 `521e1a63`，正常合并到 PR878 `822d31d0`。保留原 PR 的 ABI 清单、独立恢复入口、OPP 路径归一化与进程控制修复；相对 `521e1a63` 不修改算子 kernel。

- 删除顶层 import 的二进制字符串探测、自动 ctypes 与强制 Stable 告警继续路径。
- C++ runtime 新增显式 `fla_npu_stable_overlay_order_version() = 1`。首次 `_stable.load()` 先加载实际库并通过严格 stamp，再对同一实际路径（包括 `FLA_NPU_STABLE_LIB`）探测版本。多个 host 库启用时，缺失、旧版或异常导出均硬失败；成功后才解析算子。
- 根包 import 仍不加载 Torch；安装只验证 ACLNN ABI/产物完整性，不能宣称 launcher 能力已通过。独立 manager 仍可审计、移除无法执行的 overlay，重启后恢复。
- `test_stable_parity.py` 复用主干 before/after 记录器，在同一 Stable 后端比较签名、输入、输出、可选返回和状态版本；旧双后端报告不兼容，错误、空调用与漏测均失败。
- `build.sh --pkg` 的 scoped/full adapter/header 门禁不再受 `FLA_NPU_BUILD_STABLE_ABI=0` 豁免；wheel 入口仍按主干策略拒绝该旧模式。
