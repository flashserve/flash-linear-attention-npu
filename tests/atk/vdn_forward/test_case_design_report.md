# VDN 前向用例设计

## 参数与约束

YAML 和冻结 JSON 将 Q/K/V、beta、alpha、bounds、可选 text_state 声明为张量，将求解、预处理、帧块和尾块等选项声明为公开关键字参数。`gen_vdn_forward.py` 只关联张量的 shape、dtype 和帧界，数据由 ATK 按 JSON 中的分布和种子生成。短卷积为嵌套权重字典，使用独立 NPU 测试传入真实卷积权重。

| 输入 | 精度、值域或结构 | 校验 |
| --- | --- | --- |
| Q/K/V | [F,H,S,128]，同 dtype；Q/K ∈ [−0.08,0.08]，V ∈ [−1,1] | Q/K 单行二范数 ≤ √128 × 0.08，关闭 L2 时仍满足求逆的谱界 |
| beta / alpha | beta ∈ [0,1]；alpha 为 FP32，取值 [0.79,0.99] | beta 的 dtype 覆盖特征 dtype 和 FP32；alpha 的两端窗口乘积非平凡 |
| text_state | 可空；FP32 [H,128,128]，有值时取 [−0.025,0.025] | 单帧带文本、无文本长序列 |
| bounds | int64 [F,2] | ATK 初始化阶段将原始端点裁到包含当前帧的合法区间；CPU/NPU 使用同一张量。独立测试覆盖非法端点 |
| frame_tile | 正的 2 的整幂 | 1、4、8、32、64；独立测试拒绝 0 和 3 |
| delta_rule | vdn_solve、newton_schulz | 两个求解器各自对照同一独立 CPU 直接求解 |
| 开关 | 两个融合开关独立；pad_tail 和 value_first 均覆盖开、关 | 精度集覆盖 4 种 SiLU/L2 搭配；独立短卷积测试覆盖跨块时间 halo |

## 数据覆盖与比较

在 ATK 26.9.8 的 `gen_cases` 入口实际生成 200 个候选，覆盖两种特征 dtype 和 F=1、5、7、8、9、11、32、85、87。输入维度包含最小单帧单头、从一个到多个完整帧块、尾块、多个头以及 405 token 的 TP8 模型输入。FP32 和 BF16 的 CPU 比对按各自舍入边界进行。精度集的每项分支配置有三个不同种子，具体 id 见[测试矩阵](README.md)。性能集保留 85 帧和 87 帧的两个模型输入，仅改变求解路径。MSS 集用 FP32、BF16 和至少 192 个矩阵的 Newton 分块覆盖四个原生模板实例。

独立测试用手算三帧标量检查窗口外沿选择和文本初态，用多头拆分检查 head 间独立性；设备测试比较短卷积、SiLU、QK L2 组合后最终读出。子算子直测使用与生产相同的 Stable ABI 接口，分别检查双向状态库、非零 start 的 FP32/BF16 尾块写回、对角更新后非对角元素逐位保持。另有存储别名回归，覆盖三个原生入口的重叠拒绝及同一底层存储上不相交的连续视图。精度标准及复现命令见[测试说明](README.md)。
